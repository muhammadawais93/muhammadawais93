## 🇩🇪 My product: GermanyDesk

**[GermanyDesk](https://germanydesk.com)** is a free, plain-English toolkit for expats in Germany, designed, built and run by me. No signup, no German required, updated for the 2026 tax year, in English and German.

| Tool | What it does |
|---|---|
| [German salary calculator (Brutto Netto)](https://germanydesk.com/tools/brutto-netto) | Exact take-home pay after German taxes and social contributions |
| [Tax class calculator (Steuerklasse)](https://germanydesk.com/tools/steuerklasse) | Compare Steuerklasse 3/5 vs 4/4 using both salaries |
| [Chancenkarte calculator](https://germanydesk.com/tools/chancenkarte) | Check your Opportunity Card points for Germany's job-seeker visa |
| [Freiberufler vs Gewerbe checker](https://germanydesk.com/tools/freiberufler-gewerbe) | Find out how your freelance work is classified |
| [German health insurance guide (GKV vs PKV)](https://germanydesk.com/tools/health-insurance) | Public or private based on income and family |
| [Anmeldung checklist](https://germanydesk.com/tools/anmeldung) | Personalised documents list for address registration |

**[See all 11 tools at germanydesk.com →](https://germanydesk.com/tools)**

**Under the hood:** Next.js and TypeScript on Vercel, EN/DE versions, German tax and social contribution logic, and a weekly automated SEO audit that checks HTTP status, PageSpeed and Search Console indexing for every URL.
